# Moovs Skills

Public, provider-neutral skills for using Moovs with your preferred AI assistant.

**[Start in ChatGPT](CHATGPT-PILOT.md)** · **[Other assistants](START-HERE.md)** ·
**[Download v0.3.0](https://github.com/theswoopapp/moovs-skills/releases/tag/v0.3.0)**

## Use it

1. Paste the [setup prompt](START-HERE.md) into your assistant.
2. Ask how for one-step guidance, or ask it to do an authorized task.
3. Confirm any missing business details and review the actual saved result.

The [catalog](CATALOG.md) covers 18 domains: quotes, reservations, dispatch,
payments, contacts, settings, drivers, fleet/pricing, invoices, finance, affiliates,
Shuttle, customer portal, communications, plans, reports/help, websites and add-ons.
Load only the relevant skill and needed references, not the whole library.

## Browser access and installation

Reading these files supplies instructions for the conversation; it does not
install a skill, connect a browser or grant account permissions. When authorized
browser tools are available, assistants can perform supported tasks through
entry, selection, submission and same-record readback. Otherwise they guide you.
See [compatibility and installation](docs/compatibility.md).

Release downloads include a full bundle and individual domain ZIPs. Individual
ZIPs suit hosts that accept one skill per upload; the full bundle can be extracted.
`checksums.json` verifies file bytes, not publisher identity or product safety.

## Safety and limits

- Use the intended company and approved values. Actual host, role, plan, add-on
  and usage limits apply; a visible button is not an entitlement.
- Exact approval remains necessary for charges/refunds, sends, dispatch,
  publishing and destructive/access changes. No blanket future-action authority.
- Sign in and enter passwords, verification codes, raw payment/bank/KYC details
  and personal signatures privately. Do not impersonate another person.
- On an uncertain save/charge/send, inspect existing state before retrying.
  A toast, checklist or outgoing log is not proof of persistence or delivery.
- These are public-guide-based instructions, not certified every-feature,
  current-UI or all-host acceptance. Missing guidance stays explicit; do not
  invent unsupported controls, rates or outcomes.

## Current product guidance

Skills read relevant published Moovs Help articles when available. Public Help
is the product-guidance source of truth; local references are dated fallbacks.
Update public Intercom guidance first when instructions change, then review the
skill. Files do not automatically synchronize. See [public-source policy](docs/public-sources.md).

This repository distributes reviewed operator-facing content only. Research,
evaluations and authoring tools are not part of this public distribution.
