# Moovs Skills — public distribution

This repository distributes reviewed, public-source-based operator skills.
Read README.md, release.json and docs/public-sources.md before changes.

- Authoring, research, evaluations and tooling belong in the authorized private
  workspace, not here. Do not merge or push private authoring history into this repo.
- Publish only explicitly reviewed operator-facing files. release.json is the
  package allowlist; other public Git files still need their own privacy review.
- No customer/demo records, credentials, private code/source details, internal
  account/resource links, raw transcripts, screenshots or maintainer-only reports.
- Preserve provider-neutral HOW guidance and authorized DO execution, actual
  host/role/plan constraints, sensitive entry and exact consequential approvals.
- Keep each skill independent, its local links intact and Markdown under 200 lines.
- Verify the candidate with the authoring workspace's tests, packaging and privacy
  gates before publishing. Do not invent missing build scripts in this distribution.
- Explicit publication approval is required. Never force-push or rewrite public
  history without separate exact approval. Packaging is not host acceptance.
