# Moovs Insights

Public [pricing](https://www.moovsapp.com/pricing) lists **Moovs Insights** and
customizable analytics. The [official Insights page](https://www.moovsapp.com/moovs-insights)
describes revenue/demand and vehicle, customer and affiliate analysis, but also
offers **early access**. Neither page proves current activation for a company.
Reviewed 2026-10-15; no live analytics account inspected.

## Insights access and dashboard customization

Distinguish Insights from the standard Dashboard, Ride Report and ordinary CSV
exports. Ask what business question the operator wants answered, the reporting
period/timezone, relevant metric definition and intended audience. Use synthetic
examples rather than requesting customer exports or exact financial balances.
Confirm the actual product, role and purchased/enabled access; do not promise
Insights merely because another report is visible or the company has Enterprise.

The reviewed product page is marketing, not a literal dashboard-builder capture.
No complete public activation/navigation, dataset/metric definition, custom-chart
editor, filter/save/share or refresh/reconciliation walkthrough was established.
Read a matching current public Help guide if available. Otherwise disclose this
gap and ask Moovs for the supported instructions before changing a dashboard.
Do not invent SQL, table schemas, a report builder, scheduled-email delivery or
an integration from the word "customizable."

An explanation is not early-access, purchase, upload or export permission. Apply
task-authority.md for explicitly requested supported steps, including persistent
filters, chart edits, saves and downloads; sharing needs exact audience/content
approval. Keep raw financial identifiers private. For a supported change, compare
the saved view, intended period/filters and metric definitions, data freshness
and audience within the authorized scope. A saved dashboard is not proof of complete data or
accounting reconciliation; report only what was actually verified.

## Shuttle stakeholder report scope

A [November 21, 2025 public post](https://www.moovsapp.com/post/why-your-workplace-needs-modern-shuttle-tracking)
advertises program-manager dashboards for capacity, on-time performance, ridership
and cost per employee. It is not a report-definition or setup guide.

**Documentation gap:** metric definitions/denominators, cost allocation, program
scope, permissions, refresh and delivery/setup controls are not established here.
Identify the intended program, audience, period and metric before interpreting an
available report. Ask Moovs for supported definitions/setup; do not invent a
cost-per-employee formula, expose another client's data or treat a visible
Dashboard as an approved stakeholder export. Any supported operator sharing is a
separate reviewed action; screenshots and an aggregate number are not validation.
