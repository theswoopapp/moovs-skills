## Issue versus feature request

**? > Issue Report** is for malfunction. Draft category, impact-based priority,
expected behavior, actual behavior/error and numbered safe reproduction steps.
Use synthetic examples and redact personal/financial data. Do not paste broad
logs or reproduce consequential actions. Public priority guidance: **Low** for
minor/cosmetic issues or a workaround; **Medium** for affected functionality while
critical work continues/temporary workaround; **High** for essential tasks blocked,
data loss or broad user impact. Choose from actual impact, not a default label.
If final controls are requested, operator reviews **Submit Report** to send or
**Cancel** to abort; execute submission only with exact reviewed content/recipient
approval. A report submission is not a fix.

**? > Give Feedback** is for a product suggestion. Draft a short Title and Details
covering the goal, current friction and concrete requested improvement. Do not
promise prioritization or delivery. Operator decides whether to submit.

[Product feedback](https://intercom.help/moovs-05c940f1970e/en/articles/6871904-how-to-provide-effective-product-feedback)

## Google Calendar integration

This is a separate authorized integration, not just viewing Dispatch's calendar.
Free excludes Calendar invites; a visible Market control is not proof of access.
Check paid-plan entitlement and role before any operator authorization. Current
invite guidance locates Google Calendar under **Settings > General > Moovs Market**.
Public setup route: **Moovs Market > Google Calendar > Install and Authorize**.
Operator privately chooses/authorizes the correct business Google account. The
guide supports one account and warns initial calendar creation can take24hours.
Operator checks **My calendars** in that authorized Google account after setup;
calendar appearance alone does not prove trip/update sync.
Account authorization/installation needs exact reviewed access-scope approval;
keep login/credential entry private and do not expose OAuth links or create real test trips.

The guide says future trips/updates populate the new calendar. Drivers need an
email and must accept an assigned trip to receive an invite; unassignment or
cancellation or deletion can send cancellation email. Warn about these communications before
the operator changes a real trip. Calendar access can expose passenger/driver
contact and trip information. Verify sync through the operator, not from an
install confirmation alone; no guarantee of immediate initial setup. The article
says invite duration is estimated/actual depending on transfer/hourly, not a new
exact duration formula or permission to adjust a trip to fit its calendar block.

Sources: [Calendar integration](https://intercom.help/moovs-05c940f1970e/en/articles/7199695-about-google-calendar-integration),
[Current invite setup](https://intercom.help/moovs-05c940f1970e/en/articles/10058047-google-calendar-invites),
[Free exclusions](https://intercom.help/moovs-05c940f1970e/en/articles/9927108-important-updates-for-free-plan-users).

[Pricing](https://www.moovsapp.com/pricing) uses the broader name **Google Suite**.
The guides above document Calendar, not a Gmail/Drive synchronization contract.
Ask which Google task is intended; do not install another Google service or
invent its access scopes from that umbrella label.

## Home-screen shortcut

Operator opens the already-verified official Operator site on their own device.
Use the applicable dated Help path only if the visible controls match:

- **iPhone/iPad Safari:** bottom Share/Upload icon > **Add to Home Screen** >
  review/rename > **Add**.
- **iPhone/iPad Chrome:** Share next to address bar > **Add to Home Page** >
  review/rename > **Add** (wording as published; do not invent a missing control).
- **Android Chrome:** upper-right three-dot menu > **Add to Home Screen >
  Create Shortcut**.

Device changes require a requested task and supported authorized tools; otherwise coach. This is a browser shortcut, not a native
Operator install or proof of full feature compatibility. If controls differ,
use current browser guidance rather than guessing another install sequence.
If a feature behaves differently, retry through the normal browser/desktop.

Source: [Home-screen access](https://intercom.help/moovs-05c940f1970e/en/articles/9706934-access-moovs-on-your-home-screen-in-4-easy-steps)
