# Ordinary and custom event manifests

Reviewed2026-10-16. The public Reservation Manifest guide supports one
reservation's active/non-cancelled trips at **Links > Reservation Manifest**.
Use that ordinary read/copy workflow when it matches the task; a request for a
live reservation view does not require a custom integration or setup inquiry.

## Custom event-coordinator manifest is a separate scope

September2026 describes a custom implementation grouping event trips across
booking contacts, showing costs and custom branding, with Excel/PDF exports.
That is not a documented general self-service event builder or an entitlement
grant. The narrated synchronization claim is not a verified freshness guarantee.
Current public guidance here does not establish event grouping/setup, access
boundaries, export configuration, update guarantees or recovery for that custom
product. Obtain its current supported scope with Moovs before promising setup.
Do not inherit the ordinary manifest's no-date-filter/farmed-in rules for it,
claim ordinary **Reservation Manifest** provides cross-booking grouping, or
export/share actual event data as a diagnostic. Keep each audience's information
private and never publish the webinar's real example as a training fixture.
