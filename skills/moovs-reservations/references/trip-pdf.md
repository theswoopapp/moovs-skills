# Download and print an existing trip PDF

Reviewed 2026-10-16. January2025's Q&A describes **View PDF > download > print**
and the presenter confirms the PDF-first design. This is a dated narrated output
chain, not independently inspected frames, current UI acceptance or a complete
PDF-options editor. Do not invent a menu location absent from this source.
Follow [task authority](task-authority.md): authorized opening/download and
private artifact inspection can be assistant-owned. Do not publish customer data.

1. Confirm the company, exact existing reservation/trip, requested document and
   authorized purpose. Distinguish this trip output from an invoice, Affiliate
   PDF, manifest or legally compliant waybill; one does not establish the other.
   For merely explaining the chain, do not require an account/permission audit.
2. Open only the intended existing trip through an authorized session. Review the
   actual offered **View PDF** control and document scope before proceeding. If
   the current control/document differs, obtain current Help/Support instructions
   rather than guessing a menu or substituting an invoice. Never create/close a
   trip, send confirmation or change pricing merely to obtain a printout.
3. Operator opens the intended PDF and downloads it using the actual offered
   controls. Before printing, privately compare the resulting file's trip/reference,
   date/time and needed contents with the intended record, and check readability.
   Download is not proof the right document was produced or shared. Do not upload
   the PDF, passenger details or private links into public notes or unrelated services.
   Authorized private inspection of task-relevant contents is permitted.
4. Operator prints that checked PDF using their PDF viewer's actual print control
   and reviews destination printer, pages/copies and privacy before submission.
   This is a local-output safety check, not a claimed Moovs print-settings editor.
5. Check the actual output is the intended readable document and protect/dispose
   of unwanted copies privately. A print dialog or download alone is not a paper
   result. Without permitted direct readback, label completion operator-reported;
   an old PDF is a snapshot, not proof of current trip state or customer delivery.

The same January Q&A treated direct screen-print and confirmation-PDF font-size
editing as requests, not available controls then. Do not invent either setting
or claim a present universal prohibition from that historical answer. Stop on a
material difference. No invoice, dispatch, payment, waybill-compliance or customer
message workflow is included, and no private document is needed in this guide.
