# Optional example: a synthetic quote execution test

Reviewed 2026-10-18. The former quote-only/demo-only release restriction is
superseded by [task-scoped authority](task-authority.md), not a platform limit.
Any supported authorized task can use execution; this is merely a safe example.

For a test, the user may approve one new basic One Way quote in their synthetic
company, using approved service, existing contact/passenger/vehicle and pricing,
saved without email. The assistant operates the ordinary form controls itself,
selects the intended Save quote branch, submits once, then reopens the exact quote
to compare reference, service fields, identities, vehicle, pricing and state.

Those example boundaries apply only if chosen for that test. They do not forbid
an authorized reservation, other quote type, ordinary contact/settings task or
operational company. A changed task needs its relevant authority and business
values, not a request to “bypass” a fictional technical restriction.

Host approvals, private sensitive entry, actual plan/role/source limits and exact
financial/send/destructive-action approval still apply. A toast is not saved-state
proof; inspect an uncertain prior save before retry. Missing browser tools means
execution unavailable, not permission to claim a checklist was performed.
