# AI-Powered Driver Scheduler

Public [pricing](https://www.moovsapp.com/pricing) advertises an **AI-Powered
Driver Scheduler**. This establishes a named capability, not a configuration/run
walkthrough or entitlement for the current company. Reviewed 2026-10-15.

## Identify the intended scheduling task

Ask whether the operator means AI-generated driver scheduling, ordinary driver
availability/assignment, Auto Dispatch's driver search, or Shared Shuttle's
Scheduler Board. They are not interchangeable. Do not turn on Auto Dispatch or
edit availability to imitate the AI Scheduler.

For AI scheduling, establish the company, intended service dates/timezone and
desired result. Review only approved non-sensitive scheduling constraints needed
for that task; do not infer driver suitability from an AI recommendation or from
an empty availability warning. Check the account's actual purchased/enabled
access and role. Marketing's Enterprise references are not proof of activation.

## Public setup/run gap

No exact AI Scheduler setup, input contract, generation control, proposal review,
apply/save behavior, notification effect or recovery procedure was established
by the reviewed public sources. Fetch a relevant current public Help guide if
one is available. Otherwise explain this gap and request supported instructions
from Moovs before directing a run or application; do not invent an optimizer
button, settings path, constraint field or automatic-dispatch outcome.

The operator performs any generation that creates/saves state and all assignment
or apply actions. Do not submit a real schedule merely to test access. A generated
proposal, saved assignment and driver's acceptance are separate outcomes. When a
supported workflow is available, compare intended trips/dates/driver assignments
with saved state afterward, including unresolved conflicts; absent readback,
completion is unverified. No current Operator UI or AI schedule was tested here.
